# 阶段 0 执行计划

1. 创建父任务和阶段 0 至阶段 9 子任务，记录迁移分支、集成目标和当前工作目录。
2. 写入父任务迁移合同、阶段依赖、提交规则与停止条件。
3. 通过独立探查核对 task schema、入口模板、init/update、Codex skills、legacy upgrade marker 和现有任务机制。
4. 运行 `pnpm build`、`pnpm test`、`pnpm typecheck`、`pnpm lint`，把结果写入交接记录。
5. 核查 Git diff 只含阶段 0 的任务与规划文档，提交阶段 0。

## 回滚点

阶段 0 只有新增任务文档。若任务树或契约有误，在提交前修正文档；提交后以该提交为审计边界，用追加修正提交处理，不修改其他任务或产品源码。
