# 阶段 0 设计：基线与迁移契约

## 产物范围

阶段 0 只创建迁移父任务、十个阶段子任务、中文 PRD/设计/执行计划和阶段交接记录。它不触及 CLI、Core、模板、migration、技能或测试源码。

## 证据模型

- 代码入口地图以 `file:line`、符号名和必要关键原文记录。
- 命令基线记录完整命令、退出状态、失败摘要和是否为既有问题。
- 每一个任务产物必须位于产品 Git 仓库的 `.trellis/tasks/`，随阶段 0 的独立提交追踪。
- 本阶段当前工作目录为现有 checkout；这是迁移任务自己的执行位置，不改变未来由 Trellis 初始化出的项目默认 worktree 路径。

## 验证策略

对任务文档和 Git 状态做范围核查；对产品质量命令做基线运行。由于阶段 0 没有产品代码变更，spec-review、code-review、code-architecture-review、merge-review 均记录为不适用，不能把它们的跳过解释为后续代码阶段的豁免。
